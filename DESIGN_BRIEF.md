# ReelWith — Design brief

## Feeling
A dark theater lobby with brass and amber bulbs. Photos are honest; chrome is quiet so the moment card wins. Not Instagram clutter, not Letterboxd austerity.

## Visual system
- True dark `#0E0E14`, card `#1B1B27`, ink `#F4EFE6`, muted `#9A95A8`
- Amber accent `#E8A23A` (tickets, scores, CTAs)
- **Playfair Display** titles, **DM Sans** UI
- Moment card: 3:4 photo, PiP “crew chip”, late/on-time style badges, vibe pill
- Rating: three big emotion pills (Loved / Fine / Nah) → animated score reveal (Beli energy without the invite wall)

## Signature loops
1. **Rate loop:** pick title → emotion → with whom → save → confetti-less toast + diary bump
2. **Moment loop:** snap → tag film + crew → post → feed card with dual presence (you + film)

## Empty states
Each tab has a scene (empty theater seats / blank diary page) + one obvious CTA — never “No data.”
