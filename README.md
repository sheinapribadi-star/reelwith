# ReelWith

**Rate movies with friends. Snap who you’re watching with.**

ReelWith is a social movie diary — Beli-style ratings mixed with a BeReal-style “watch moment” (photo + crew + caption). Built as a warmer, more social alternative vibe to Letterboxd.

**Live demo:** https://sheinapribadi-star.github.io/reelwith/

## Features

- ⭐ Log & rate films (1–10) with a short one-liner
- 📸 Watch moments — camera or upload, tag who you’re with, pick a vibe
- 👥 Feed of moments (yours + sample friends)
- 📓 Personal diary with average score
- 🎬 Curated catalog (no API key). Ready to swap for TMDB later.
- 💾 All data stays in `localStorage` for the MVP

## Stack

Vite + vanilla JS. Hand-crafted dark cinema UI (Playfair Display + DM Sans).

## Develop

```bash
npm install
npm run dev
npm run build
```

GitHub Pages serves `dist/` from the `main` branch (`/reelwith/` base path).
